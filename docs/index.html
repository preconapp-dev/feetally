How these calculators work

Official rates only

Each calculator is built from the platform's published fee schedule and links to the exact page. No rounded "about 10%" guesses.

Dated and re-checked

Every page shows when its fees were last verified. Recent changes are logged so you can see what moved.

Profit, not just fees

Add what the item cost you and see profit, margin, break-even price and the price you'd need for a target profit.
